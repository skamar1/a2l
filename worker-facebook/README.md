# a2l-fb-poster

Κοινοποιεί αυτόματα τα νέα άρθρα του `a2l.gr` στη σελίδα **A2 Labs** στο Facebook.

Κάθε **Τρίτη 10:00** (ώρα Αθήνας) διαβάζει το `https://a2l.gr/odigies-nea/index.xml`,
βρίσκει τι δεν έχει δημοσιευτεί ακόμα και ανεβάζει **ένα** άρθρο.

## Πώς αποφασίζει

| Κατάσταση | Τι κάνει |
|---|---|
| Πρώτη εκτέλεση (KV άδειο) | Σημειώνει όλα τα υπάρχοντα άρθρα ως δημοσιευμένα και **δεν ποστάρει τίποτα**. Χωρίς αυτό θα έβγαζε έξι αναρτήσεις μονομιάς. |
| Υπάρχει νέο άρθρο | Το ποστάρει και το γράφει στο KV. |
| Πάνω από ένα νέο | Ποστάρει το πιο πρόσφατο· τα υπόλοιπα την επόμενη εβδομάδα. |
| Τίποτα νέο | Δεν κάνει τίποτα. Σιωπή είναι σωστότερη από ανακυκλωμένο περιεχόμενο. |
| Το άρθρο έχει δική του εικόνα | Ανάρτηση **φωτογραφίας** με το OG banner (μεγάλη εικόνα στο feed). |
| Δεν έχει δική του εικόνα | Ανάρτηση **συνδέσμου** — μια φωτογραφία με σκέτο το λογότυπο δεν λέει τίποτα. |

Η εικόνα και η περιγραφή διαβάζονται από τα `og:image` / `og:description` της
ίδιας της σελίδας, δηλαδή από ό,τι παράγει το `layouts/partials/head.html`.

## Τι δεν κάνει σιωπηλά

Κάθε αποτυχία στέλνει email στο `info@a2l.gr` μέσω SMTP2GO. Το KV γράφεται
**μετά** την επιτυχή δημοσίευση, οπότε ένα αποτυχημένο ποστ ξαναδοκιμάζεται την
επόμενη φορά αντί να χαθεί.

## Μυστικά

Κανένα δεν μπαίνει σε αρχείο — το repo είναι δημόσιο.

```sh
op read 'op://Private/Facebook token για το Α2L/password' | wrangler secret put FB_SYSTEM_TOKEN
wrangler secret put SMTP2GO_API_KEY
wrangler secret put TRIGGER_KEY
```

Το `FB_SYSTEM_TOKEN` είναι token **χρήστη συστήματος** και δεν λήγει ποτέ. Ο
Worker ζητάει από αυτό το token της σελίδας σε κάθε εκτέλεση, οπότε δεν
χρειάζεται δεύτερο μυστικό ούτε ανανέωση.

## Δοκιμή

```sh
# τοπικά, χωρίς να αγγίξει το Facebook
wrangler dev --var TRIGGER_KEY:testkey --var FB_SYSTEM_TOKEN:dummy
curl -H "X-Trigger-Key: testkey" "http://localhost:8787/run?dry=1"
```

Το `?dry=1` δείχνει τι θα δημοσιευόταν (κείμενο, εικόνα, τρόπος) χωρίς να
δημοσιεύσει. Χωρίς σωστό `X-Trigger-Key` η διεύθυνση απαντάει 404.

## Deploy

```sh
wrangler deploy
```

Το `workers_dev = false`: ο Worker δεν έχει δημόσια διεύθυνση, τον ξυπνάει μόνο
το cron. Για χειροκίνητη εκτέλεση χρειάζεται προσωρινά `workers_dev = true`.
