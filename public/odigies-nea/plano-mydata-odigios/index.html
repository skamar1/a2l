Οδηγός myDATA: Ηλεκτρονική Διαβίβαση Παραστατικών με το Plano

Βήμα προς βήμα οδηγός για τη σύνδεση του Plano ERP με το myDATA της ΑΑΔΕ.

Τι είναι το myDATA

Το myDATA (My Digital Accounting and Tax Application) είναι η πλατφόρμα ηλεκτρονικής διαβίβασης παραστατικών της ΑΑΔΕ. Από το 2021, όλες οι ελληνικές επιχειρήσεις υποχρεούνται να διαβιβάζουν τα παραστατικά τους ηλεκτρονικά.

Σύνδεση Plano με myDATA

Βήμα 1: Απόκτηση κλειδιών API

  1. Συνδεθείτε στο myAADE με τους κωδικούς Taxisnet
  2. Μεταβείτε στο myDATA → Διαχείριση → API Keys
  3. Δημιουργήστε νέο API Key
  4. Αποθηκεύστε το User ID και το Subscription Key

Βήμα 2: Παραμετροποίηση στο Plano

  1. Ανοίξτε Ρυθμίσεις → Ηλεκτρονική Τιμολόγηση
  2. Εισάγετε τα στοιχεία API
  3. Επιλέξτε περιβάλλον: Παραγωγή ή Demo
  4. Κάντε Test σύνδεση

Βήμα 3: Ρύθμιση τύπων παραστατικών

Για κάθε τύπο παραστατικού (ΤΔΑ, ΑΠΥ, κ.λπ.) πρέπει να ορίσετε:

  • Κατηγορία παραστατικού myDATA
  • Κατηγορία ΦΠΑ
  • Κατηγορία εσόδων/εξόδων

Συνηθισμένα Προβλήματα

Σφάλμα: “Invalid credentials” → Ελέγξτε ότι χρησιμοποιείτε το σωστό User ID (ΑΦΜ εταιρείας).

Σφάλμα: “Document already exists” → Το παραστατικό έχει ήδη διαβιβαστεί. Ελέγξτε το ιστορικό.
